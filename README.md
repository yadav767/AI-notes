# AI Notes

AI Notes is a full stack web app that turns any topic into exam-ready study notes. You enter a topic and your exam type, choose a few options, and the app generates sub-topics grouped by importance, notes, practice questions, and optionally a diagram and charts. Every note is saved, so you can open it again later or download it as a PDF.

**Live app:** https://ai-notes-silk.vercel.app
**API:** https://ainotes-server.vercel.app

## Features

- Sign in with Google (Firebase Authentication)
- Generate notes from any topic using the Gemini API
- Options for exam type, **Revision Mode** (short last-minute notes), **diagrams** and **charts**
- Sub-topics grouped into three importance levels, plus short and long practice questions
- Flowcharts rendered with Mermaid and charts rendered with Recharts
- History page to reopen any note you generated earlier
- Download notes as a PDF
- Credit system: every new user gets 50 free credits and each generation costs 10
- Buy more credits with Stripe Checkout
- Protected routes on both the frontend and the backend

## Tech Stack

**Frontend:** React 19, Vite, Tailwind CSS, Redux Toolkit, React Router, Axios, Framer Motion (`motion`), react-markdown, Mermaid, Recharts

**Backend:** Node.js, Express 5, MongoDB with Mongoose, JSON Web Tokens, Google Gemini API (`@google/genai`), Stripe, PDFKit

**Services:** Firebase Authentication, Stripe Checkout, Vercel (frontend and backend are deployed separately)

## How It Works

1. The user signs in with Google. Firebase handles the popup, then the frontend sends the name and email to the backend.
2. The backend creates the user (50 free credits) or finds the existing one, and sets a JWT in an `httpOnly` cookie.
3. On the Home page the user enters a topic and picks the options. The backend checks that they have at least 10 credits.
4. The backend builds a detailed prompt and asks Gemini to reply in a fixed JSON format (sub-topics, notes in Markdown, revision points, questions, Mermaid diagram, chart data).
5. The JSON is parsed, saved in MongoDB, and 10 credits are deducted.
6. The frontend renders the result with Markdown, Mermaid and Recharts. The user can download it as a PDF generated by the server.
7. When credits run out, the user buys a plan through Stripe Checkout. The credits are added only after Stripe confirms the payment through a signed webhook.

## Credit Plans

| Price | Credits |
| ----- | ------- |

## API Endpoints

| Method | Endpoint | Auth | Description |
| ------ | -------- | ---- | ----------- |
| GET | `/health` | No | Server health check |
| POST | `/api/auth/google` | No | Create or find the user and set the login cookie |
| GET | `/api/auth/logout` | No | Clear the login cookie |
| GET | `/api/auth/current-user` | Yes | Get the logged-in user |
| POST | `/api/notes/generate-notes` | Yes | Generate and save new notes (costs 10 credits) |
| GET | `/api/notes/getnotes` | Yes | List the user's saved notes |
| GET | `/api/notes/:id` | Yes | Get one saved note |
| POST | `/api/pdf/generate-pdf` | Yes | Download notes as a PDF |
| POST | `/api/credit/order` | Yes | Create a Stripe Checkout session (`amount`: 100, 200 or 500) |
| POST | `/api/credits/webhook` | Stripe | Stripe webhook that adds credits after payment |

Example request for `/api/notes/generate-notes`:

```json
{
  "topic": "Web Development",
  "classType": "Class 10",
  "examType": "CBSE",
  "revisionMode": false,
  "includeDiagram": true,
  "includeChart": true
}
```

## Getting Started

### Requirements

- Node.js 18 or higher
- A MongoDB database (local or MongoDB Atlas)
- A Gemini API key
- A Firebase project with Google sign-in enabled
- A Stripe account (test mode is fine)

### 1. Clone the repo

```bash
git clone https://github.com/yadav767/AI-notes.git
cd AI-notes
```

### 2. Set up the backend

```bash
cd server
npm install
```

Create a `.env` file inside `server/`:

```
PORT=5000
MONGODB_URL=your_mongodb_connection_string
JWT_SECRET_KEY=any_long_random_string
GEMINI_API_KEY=your_gemini_api_key
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret
CLIENT_URL=http://localhost:5173
```

Start the server:

```bash
node server.js
```

### 3. Set up the frontend

```bash
cd client
npm install
```

Create a `.env` file inside `client/`:

```
VITE_FIREBASE_API_KEY=your_firebase_api_key
```

The rest of the Firebase config is in `client/src/utils/Firebase.js`. Replace it with your own Firebase project's values if you are not using the original project.

Start the app:

```bash
npm run dev
```

### 4. Point the app to your local backend

The production URLs are set in the code, so for local development change these two places:

- `client/src/App.jsx`: set `serverUrl` to `http://localhost:5000`
- `server/src/app.js`: set the CORS `origin` to `http://localhost:5173`

The login cookie is set with `secure: true` and `sameSite: "None"`, so it works on `localhost` in Chrome but may need HTTPS in other browsers.

### 5. Test Stripe payments locally (optional)

Install the Stripe CLI and forward webhooks to your server:

```bash
stripe listen --forward-to localhost:5000/api/credits/webhook
```

Copy the webhook signing secret it prints into `STRIPE_WEBHOOK_SECRET`. Use Stripe's test card `4242 4242 4242 4242` at checkout.

## Environment Variables

| Variable | Where | Purpose |
| -------- | ----- | ------- |
| `PORT` | server | Port for the Express server (default 5000) |
| `MONGODB_URL` | server | MongoDB connection string |
| `JWT_SECRET_KEY` | server | Secret used to sign login tokens |
| `GEMINI_API_KEY` | server | Gemini API key |
| `STRIPE_SECRET_KEY` | server | Stripe secret key |
| `STRIPE_WEBHOOK_SECRET` | server | Stripe webhook signing secret |
| `CLIENT_URL` | server | Frontend URL used for Stripe success and cancel redirects |
| `VITE_FIREBASE_API_KEY` | client | Firebase web API key |

## Deployment

Both folders are deployed on Vercel as two separate projects. The frontend uses a `vercel.json` rewrite so React Router works on page refresh, and the backend uses `@vercel/node` to run `server.js`.
